# p!ckd

Diário de cinema e TV: notas de meia em meia estrela para filmes, séries, animes e episódios, com onde assistir no Brasil.

Neste site o p!ckd abre em **modo leitura**: dá para navegar pelos títulos, mas criar conta e dar notas só funciona na versão publicada no Claude, onde as notas de todos ficam juntas.
