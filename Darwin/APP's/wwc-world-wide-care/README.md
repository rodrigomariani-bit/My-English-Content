# WWC – World Wide Care

App sobre meio ambiente (Projeto de Inovação Digital · tema *Environment*): reciclagem, dicas sustentáveis,
desafios ambientais, perfil com pontuação, mapa-múndi de comunidades com doação direta sem taxas,
chat internacional e a apresentação do projeto com o pitch de 1 minuto em inglês.

## Como abrir

- **`index.html`** – o app completo em um único arquivo. Baixe e abra com dois cliques no navegador.
- **`APRESENTACAO.md`** – as 6 respostas do projeto e o roteiro do pitch em inglês, com tradução.
- **`codigo-fonte/`** – o projeto em React + TypeScript. Para rodar no computador, com o [Node.js](https://nodejs.org) instalado:

```bash
cd codigo-fonte
npm install
npm run dev
```

Depois abra o endereço que aparecer no terminal (normalmente http://localhost:5173).
O `codigo-fonte/README.md` explica as funcionalidades, a estrutura das pastas e os outros comandos.
